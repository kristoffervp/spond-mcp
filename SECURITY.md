# Security

## Reporting a vulnerability

Report it privately through [GitHub's vulnerability reporting](https://github.com/kristoffervp/spond-mcp/security/advisories/new), not in a public issue. Describe what you found and how to reproduce it.

Never include sign-in files from `.data/`, tokens, or real club, team or family data, in a report or an issue.

## Supported versions

Only the latest release gets fixes.

## Scope

This covers the code in this repository: the local server, the sign-in and token renewal, and how Spond data is filtered before it reaches the AI client. Problems in the Spond service itself belong to Spond AS, not to this project.
